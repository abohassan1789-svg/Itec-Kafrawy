A-H CODE — نماذج «مرتجع المشتريات» (المرحلة 7)

نفس شكل «فاتورة الشراء» اللي اخترته (النموذج 9 — شكل الفاتورة السعودية وأخضر البرنامج): الأزرار فوق ← بيانات المرتجع ← التفاصيل والإجماليات جنبها ← «إضافة صنف» تحت. كل نموذج في صفحة لوحده (الأرقام فوق أو الأسهم)، والبيانات وهمية، وكل النماذج شغالة على نفس المرتجعات.
